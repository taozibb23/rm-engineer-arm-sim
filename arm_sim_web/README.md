# arm_sim_web — 3D 网页模拟器

> 合成 / 仿真级，非实机。纯 SVG + 原生 JS，**零依赖、零联网、无服务器**。

## 打开

浏览器直接打开 `index.html`（双击即可）。用的是实物三自由度模型（不是四轴教学版）。

## 能看 / 玩什么

- **▶ 自动抓取演示**：臂自动跑 `识别→预抓取→接近→拾取→抬起→搬运→对准→装配→完成`，
  夹爪开合、把物体夹起搬到安装位。不用学，点开看效果。
- **3D 臂**：拖动旋转视角、滚轮缩放。
- **滑条**：拖 `ψ`/`α`/`β` 实时看末端怎么动。
- **IK**：输入目标 xyz，列出肘上/肘下两解，点哪个臂动到哪个。
- **可达圈**：工作空间边界。

## 文件

| 文件 | 职责 |
|---|---|
| `arm_kinematics.js` | 纯数学核心（FK/IK/可达/自检），对齐 C++，node 可单测 |
| `app.js` | SVG 3D 渲染 + 轨道交互 + 滑条 + IK + 抓取演示状态机 |
| `index.html` / `style.css` | 页面与样式 |

## 验证

```bash
node test_web.js     # 无头功能测试：渲染/坐标系/闭环/噪声/演示
```
数学核心自检：`node -e "console.log(require('./arm_kinematics.js').selfTest().why)"`。
数学与 `arm_sim_lab` 同源，对齐 C++ `level_arm.cpp`。

## 边界

物体是教学立方体，非真实识别；`GRASP_DROP=0.030m` 是教学假设；无碰撞/动力学；非物理仿真。
坐标链/ArUco 定位未接；实物 IK 的 C++ 实现仍需本人编写。
