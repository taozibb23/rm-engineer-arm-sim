## 明天学习顺序（一次一个，每个约 15–30 分钟）

### 第 1 步：看效果（建立直觉，5 分钟）
浏览器打开 `arm_sim_web/index.html`：
1. 点 **▶ 自动抓取演示**，看臂怎么抓→搬→放。
2. 点 **坐标系**，看 基座B→工具T→相机C→目标H 四个坐标系（x红/y绿/z蓝）。
3. 点 **闭环模式**，再跑演示，看"相机估计"标记和估计误差——这就是视觉闭环。
4. 拖**噪声滑条**，看误差变大、抓取变不准。

### 第 2 步：两关节手算（M2 核心，你的考核缺口）
先**纸笔手算**下面 3 题，再 `cd arm_sim_lab && python3 arm_sim.py --verify` 核对。

**正解公式**（L1=L2=0.149m）：
```
r = L1·cosα + L2·cosβ,  z = L1·sinα + L2·sinβ,  x=r·cosψ, y=r·sinψ
```
**逆解公式**（引入肘部相对角 θ2=β−α）：
```
ψ=atan2(y,x), r=hypot(x,y)
c2=(r²+z²−L1²−L2²)/(2·L1·L2)      ← 余弦定理
θ2=±acos(c2)                       ← ± 是两解
α=atan2(z,r)−atan2(L2·sinθ2, L1+L2·cosθ2),  β=α+θ2
可达：−1≤c2≤1
```

**练习**（先自己算）：
1. 目标 `(0.298, 0, 0)`（完全伸直）：c2=? α,β=? 为什么是边界？
2. 目标 `(0.5, 0, 0)`：为什么无解？
3. 目标 `(0.149, 0, 0.149)`：算出**两组**解，体会"多解"。
4. 思考：为什么实物不能像四轴教学版那样给末端任意 pitch？

<details>
<summary>参考答案（算完再展开）</summary>

1. c2=+1，θ2=0，α=β=0。边界：手臂伸直，c2 取最大值 1，两解重合（奇异）。
2. 0.5 > L1+L2=0.298，c2>1，超出可达球壳，无解。
3. c2=0，θ2=±90° → (α=90°,β=0°) 与 (α=0°,β=90°)。同一点两组关节角。
4. 实物只有 3 主动自由度(ψ,α,β)+连杆保水平，无腕 pitch；末端姿态被约束为水平且仅随 yaw，不能独立俯仰，故不能任意满足六维姿态。
</details>

### 第 3 步：坐标链（M3）
网页开**坐标系**，对照 `arm_sitl/camera.py` 看懂：
- `T_base_tool(q)`：正运动学，随关节变。
- `T_tool_camera`：手眼外参，**固定**（待实测标定）。
- `T_camera_target`：相机看到的目标位姿。
- 关键：**云台 IMU 四元数只给旋转，代替不了随关节变化的平移**；云台外参不能移植到末端相机。

### 第 4 步：跑闭环（M4/M5）
```
cd arm_sitl && python3 run.py --trace
```
看 `识别→预抓取→接近→拾取→抬起→搬运→对准→装配→完成`，读 `sitl.py` 的任务状态机和 `protocol.py` 的帧。
