## 二、面试 Q&A（先自己答，再对照）

**Q1：讲讲这个臂的自由度和为什么末端保持水平。**
A：3 主动自由度——底座 yaw ψ、大臂仰角 α、小臂仰角 β（都相对水平）。平行连杆机构让末端不随大小臂俯仰，只随 yaw 转。**所以只能定位置 + 水平姿态，不能任意满足六维姿态**（无腕 pitch）。这也是装配任务要先确认"需不需要倾斜"的原因。

**Q2：正运动学怎么算？**
A：`r = L1·cosα + L2·cosβ`，`z = L1·sinα + L2·sinβ`，再 `x=r·cosψ, y=r·sinψ`。末端姿态 = Rz(ψ)。

**Q3：逆运动学怎么推？为什么有多解？**
A：引入肘部相对角 θ2=β−α，化标准两连杆。余弦定理 `c2=(r²+z²−L1²−L2²)/(2L1L2)`，`θ2=±acos(c2)`——**± 就是肘上/肘下两解**。`α=atan2(z,r)−atan2(L2 sinθ2, L1+L2 cosθ2)`，`β=α+θ2`。可达条件 −1≤c2≤1。多解所以要配限位 + 选解策略（选离当前最近的解避免肘部翻转）。

**Q4：手眼坐标链每一项是什么？为什么云台外参不能直接用？**
A：`T_base_tool(q)` 正运动学随关节变；`T_tool_camera` 手眼外参固定（待标定）；`T_camera_target` 相机看到的目标。云台 IMU 四元数**只给旋转**，代替不了随关节变化的平移；云台相机和末端相机安装不同，外参不可移植。

**Q5：SITL 闭环怎么跑？为什么用估计而不是真值？**
A：仿真相机由真值目标 + 当前关节算出相机系观测（加噪声），后端坐标链反算基座系**估计**，任务状态机用估计驱动 IK→协议帧→仿真 MCU→植物→关节反馈，下一帧相机用新关节。**用估计才是闭环的意义**——验证整条链在噪声/丢帧下是否稳。

**Q6：协议怎么设计的？怎么保证可靠？**
A：仿 RoboLink 帧（头/版本/类型/长度/载荷/CRC32）。臂控制帧含关节目标 + 夹爪 + seq + 时间戳；反馈帧含实际关节 + 状态位。**CRC 篡改拒绝有测试**。但臂帧编号是占位，现有 RoboLink 只有云台帧，需电控登记。

**Q7：你怎么验证的？哪些没验证？**
A：验证了——运动学对齐 C++、协议编解码 + CRC、零噪声坐标链往返 ~1e-18m、闭环放置、抗噪、20% 丢帧、不可达不崩溃。**没验证**——实机精度、真实识别、接触力、手眼标定、传动映射。仿真级结论不冒充实机。

**Q8：哪里是 AI 做的，哪里是你做的？**
A：如实答——脚手架/实现 AI 辅助，我负责理解推导、手算核对、跑测试验证、判断边界。关键运动学我能手推（现场推 Q3）。**不要假装全自研，也不要贬低自己的理解/验证工作。**
